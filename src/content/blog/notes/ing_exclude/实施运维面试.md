# 实施流程

时间：看项目规模

- 短1-1.5月
- 长3+月

## 项目启动阶段3天

成立项目组、前期调研、编制项目总体计划、启动会
开发组：前期准备；项

| 角色     | 职责                                                         |
| -------- | ------------------------------------------------------------ |
| 开发组   | 前期准备；项目部署包，部署说明书，项目合同(**金额和功能清单**), **市场人员是否答应客户合同之外的需求** |
| 公司     | 指定项目经理，成立项目组                                     |
| 项目组   | 与用户成立实施组织，调研《用户及合同信息表》,计划，启动会    |
| 商务经理 | 建立项目组和用户的联系                                       |
| 用户     | 配合上面的，签署计划和协议                                   |

《项目总体计划》：描述，目标，阶段，里程碑，成果,职责分配(包括用户)和**沟通管理、质量管理**
启动会：《项目实施协议》、《项目总体计划》、《交接单》、《内部联系人》

## 需求调研确认阶段5天

《需求调研计划》内部评审(项目组，项目经理，商务经理等)，用户签署/变更
《需求调研通知》+《需求调研手册》(业务流程，单据使用，打印格式，报表查询->深入全面的个性化需求)->《需求分析报告》评审
《需求分析报告确认通知》发给用户确认

《需求分析报告》：功能,数据,业务流程接口,性能,安全

阶段文档：《用户联系方式》、《需求确认单》、《需求规格说明书》、《调研计划》、《调研报告》

调研内容：组织结构，职责分工；业务框架；功能模块设计部门；管理制度；企业现状；网络配置，人员强弱
业务需求：基础数据，业务流程，报表，界面，其他(个性化)
需求分类：软件收益、领导关注的、操作者需求、无法解决的需求、操作者关注单无法解决的

变更流程：实施项目组内部沟通-和客户方沟通-告知需求人员

| 系统交付确认 | 和用户确认模块功能，整理用户意见，签《系统/软件功能确认单》 |
| 需求变更     | 用户签《需求变更单》                                        |

阶段文档:《系统功能确认单》、《系统详细设计报告》、《项目二次开发计划》

## 系统安装测试及试运行阶段

- 确保各项功能正常使用,符合需求
- 把潜在问题发现并改正
- 进一步提高有关人员的操作水平

《测试及试运行计划》->签署计划->通知计划;
搭建环境及数据准备->组织测试及试运行->总结《测试报告》|《系统试运行申请单》

- 跟踪单据流转情况
- 跟踪业务流程执行状况
- 观察操作人员操作表现
- 观察系统运行速度及异常
- 观察数据正确性
- 及时纠正错误操作

# 业务问题

## 公司类型

(项目：一定时间和一定预算内达到预期目的)

- 代理型，承包成熟软件系统服务权(销售、实施、售后)(代理金蝶，用友)
- 外包型，项目外包、人力外包
- 产品(通用)型，重复销售，利润高，通用性强、软件成熟度高
- 项目型，定制销售一次，成本高，个性化强，功能成熟低

产品型优点：

- 购买通用、标准套装软件->省去开发时间，上线速度快
- 专业化程度高、功能相对齐全、上线风险小
- 价格适中，成本分摊到用户上
- 售后服务专业，产品能不断升级，适当调整

## WMS仓库管理系统

解决问题：

- 物料存储位置不明确
- 数量控制不准确
- 仓库场地不够用
- 急需物料警戒值

仓库管理原则：先进先出，锁定库位(编码)，专料专用
六不入：有送货单无货物、有货物无送货单、实物和单子型号对不上、IQC质检没通过、未办入库手续，单子不是原件
五不发：无提料单、质量不合格、规格不对，配件不齐、未办理手续

专业名词：
SKU，stockkeepingunit库存量单位，以件，盒，托盘等为单位
波次：批处理，例如拣货环节，优化拣货人员的工作路径

核心表单：
物料采购计划申请单和收货单、采购入库验收单、物料领用单 

基础数据：存库商品信息、进出库记录、库存量、盘点数据
入库：进货(采购)，产出(产品)，调入(仓库间)
出库：销售、生产(原材料)、采购退货、调出、试用、报废

分拣设备：电子标签显示设备(显示分拣任务和分拣错误报警)、无线手持数据终端(读取传输条码信息)

仓库作业:盘点(统计数据)、分拣(提取货物)、移位(仓库间转移)

模块：权限、采购、物料、产品、销量显示、预警、容纳
推及到作用说明，大小，期限，高峰值，预算，损耗

流程：采购订单-》财务收款-》库存余量-》

## 总体业务流程

我最近实施的项目是一个生产制造类的ERP系统。项目模块包括销售，采购，财务，生产，库存。
首先销售模块包括销售订单管理，客户，报价管理，合同管理，售后管理，销售业绩，销售渠道，销售预测各个功能。
（销售模块：销售订单管理，客户，报价管理，合同管理，售后管理）
**销售部门**将销售合同交给**车间总调室人员**，总调室人员根据仓库成品的库存量，与**车间设计人员**一同完成用料预测单并（这里物料是用于订单生产，第二种是库存达到预警值需要主动去补充物料，第三种是车间日常消耗品），总调室调度人员综合考虑后进行MRP运算，并对系统规划的采购计划进行适当调整，**采购部门**根据**原材料采购计划与供应商物料价格**计算所需金额，向**财务**提交用款计划，财务部门审核通过后下达**采购订单**。采购部门后续制定**订单跟踪计划**，保证物料质量、数量按期交货。
（采购模块：采购订单管理，供应商管理，询价，采购跟踪（分批次叫料））
（车间物料计划：综合考虑**销售订单+库存预警+日常消耗**来制定物料采购计划）
由生产部门的总调室人员根据先前的**销售订单以及库存量**发达**生产任务**； 生产车间设计根据生产任务和SOP图纸等技术文件算料并填写领料单，再到仓库领料；生产车间按照生产任务完成生产后，填写完工通知单并让质检部门检验合格后填写质检单。
（生产模块：生产计划，生产工单，生产领料，技术图纸，人工成品质检）
库房管理人员根据**质检单和完工通知单**办理入库，并填写成品入库单；最后仓储部门根据之前的销售订单和财务对尾款的确认审核通知来讲成品销售出库。
（库存模块：物料入库/退货，成品入库/退货，销售出库/退货，半成品外协加工入库，库存盘点，分拣，调拨，库存预警）
