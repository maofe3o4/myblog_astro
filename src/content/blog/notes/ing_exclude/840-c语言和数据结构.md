## C语言程序设计

### 概述

| C语言特点            |                  |
| -------------------- | ---------------- |

- 英文，数字，下划线

#### 语言风格

- 大括号{}标识一个语句组，即一个复合语句

#### C程序结构

- 一个或多个函数构成
- 至少一个main的主函数

### 函数

#### 函数定义

```c
//现代格式
数据类型 函数名（形参）{
    函数体
}
//传统格式
数据类型 函数名（形参）
形参说明;
{
  函数体
}
```

- 函数为定义返回类型，默认为int
- 函数由函数首部和函数体组成
- 函数之间允许直接递归调用也允许间接递归调用

| 函数存储类型 |                                                |
| ------------ | ---------------------------------------------- |
| static       | 静态函数，只限于本编译单位中的其他函数调用     |
| extern       | 外部函数，可省略，可被其他编译单位中的函数调用 |

| 变量 | | |
| --- | --- | --- |
| 局部变量 | auto动态存储区必须赋初值static只赋一次初值，默认为0或空字符register寄存器变量，执行更快 | 函数形参属于局部变量，作用域定该变量的函数或复合语句 |
| 全局变量 | | |

- 在内存中给用户使用的存储空间包括程序区，静态存储区和动态存储区
- C语言的函数都是单值函数，return一个

### 指针

- &取地址，* 取值(解引用)
- 一个指针指向的变量的数据类型称为该指针的基类型
- 数组a[i],中括号叫访问数据运算符，属于二目运算，访问以a为起点的第i个数据
- [ ]的优先级高于 *

#### 指针表示数组a[i] [j]的地址

- a[i] +j
- *(a+i)+j
- a[0]+4*i+j  假设4列

```c
//错误，不能这样赋值
char str[10];
str="asb fasfasd";
//正确，字符指针保存字符串的首地址
char *str;
str="asb fasfasd";
```

#### 函数指针

```c
int (*func)();  //一个指向返回值是int型的函数，保存该函数的入口地址
(*func)()           //调用该函数
```

### 结构体和共用体

- 定义时不占用存储空间，定义变量时才占用

#### 定义结构体

```c
//先定义结构体类型再定义变量
struct 结构体名a {};
struct a 结构体变量1,结构体变量2
//定义结构体类型同时定义变量
struct 结构体名{} 结构体变量1,结构体变量2;
//直接定义结构体变量
struct {} 结构体变量1,结构体变量2;
```

#### 引用结构体成员

- **结构体变量名.结构体成员名**
- 结构体指针变量可以通过**指针名->成员名**

#### 初始化

- 结构体变量为全局变量或者静态变量，才能初始化
- 结构体嵌套，初始化按顺序写初始值

```c
//例如
struct str1{int a;}
struct str{
  int b;
  struct str1 str11;
  char c;
} temp={2,1,c};
```

#### 共用体union

- 不能在定义共用体变量时初始化
- 共用体变量所占内存字节数与成员中最长的相等
- 不能把共用体变量作为函数参数，但可以使用指向共用体变量的指针作为函数参数

#### 枚举enum

- 一个命名为整型常量的集合
- 默认初始化从0开始

```c
//此时枚举内部按整形输出结果为0，1，2，3，4，5，6，7
enum week_day {mon,tue,wed,thu,fri,sat,sun} week；
week=fri
printf("%d",week); //结果为4
//此时枚举内部按整形输出结果为0，1，2，10，11，12，13，14
enum week_day {mon,tue,wed,thu=10,fri,sat,sun} week；
week=fri
printf("%d",week); //结果为11
```

#### 自定义类型typedef

```c
typedef struct a{} aaa;
aaa a;   //定义一个名为a的struct a类型的变量，aaa等价struct a{}
```

### 位运算

位复合赋值运算：a<<=b   等同于 a=a<<b

#### 位段

```c
//位段结构体
//位段结构体的成员说明 <数据类型> <成员名>:<整数>
//数据类型只能是unsigned和int
struct a{
    unsigned a:1;
    unsigned b:2;
    unsigned c:3;
}
a,b,c分别占1位，2位，3位，共占一个字节
```

- 将具有不同含义的**多个小整数**存放**在一个机器字**中
- 如果一个字节**剩下的空间不能容纳一个位段**，则该位段放在下一个字节；上一字节的空位叫空穴
- 位段**没有名字**表示该部分**空间不用**
- 位段只能**作为结构体成员，不能作为共用体成员，也不能定义位段数组**

### 文件

- C语言把文件看作一个字符序列
- 根据数据组织形式，分为文本文件和二进制文件
- 文本文件一个字节放一个ASCII码，文本结束标志0X1A
- FILE类型是结构体类型，定义文件类型指针变量
- C语言把所有外设都作为文件

| 常用外设   | 系统命名  |
| ---------- | --------- |
| 键盘       | KYBD或CON |
| 显示器     | SCRN或CON |
| 打印机     | PRN或LPT1 |
| 异步通信口 | AUX或COM1 |

#### 常用文件函数

mode：

- r 、w、a、rb、wb、ab     读写追加(文本文件)，读写追加(二进制文件)
- r+、w+、a+、rb+、wb+、ab+   读再写、写再读、读再追加(文本文件)

fp=fopen(fname,wb)

fclose(fp)

| 函数 | 返回值 | 说明 |
| --- | --- | --- |
| fopen(fname，mode) | 成功打开返回非0 | 以mode模式来打开文件 |
| fclose(fp) | 关闭成功放回0，否则返回-1 | 关闭文件并清除缓存区 |
| fgetc(fp) | 返回该字符，否则返回-1 | 从文件中读取一个字符 |
| fputc(c,fp) | | 把一字节的字符c写入到文件里 |
| fgets(str,n,fp) | 读取到**文件末尾，回车符，n-1个字符**，读取结束 | 从文件中读取n个字符保存在str |
| fputs(str,fp) | 出错返回EOF(-1) | str写入到fp |
| fprintf(fp,format,arg1,arg2...) | format和printf的格式符一致 | 把格式化的数据输入到文件中去 |
| fscanf(fp,format,&arg1,&arg2...) | | 把文件中读取格式化的数据 |
| fwrite(buf,size,count,fp) | | 从buf为首地址的内存中取count次数据，每次取size字节，写入到文件中 |
| fread(buf,size,count,fp) | | 从文件中读count次数据，每次读size字节，存放到buf指定的内存去 |
| ftell(fp) | | 获取当前文件指针的位置 |
| fseek(fp,offset,from)对于文本文件一般位移量为0 | 起始位置0(文件开头)，1(文件当前位置)，2(文件末尾) | 将文件指针移到从from位置开始位移offset字节处 |
| rewind(fp) | | 将文件指针指向文件开头 |
