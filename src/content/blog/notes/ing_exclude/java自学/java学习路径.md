## 框架阶段(顺序)尚硅谷

- javaweb框架，java网页应用开发基础(前端基础，xml，json，servlet，filter，listener，jsp，jstl，cookie，session)
- spring5，java轻量级应用框架(ioc，aop，事物)
- springMVC，java轻量级web开发框架(请求与响应，restful api，拦截器，配置，执行过程)
- mybatis，数据访问框架，操作数据库进行增删改查(增删改查，全局配置，动态SQL，缓存)
- maven
- springboot2，简化spring应用的初始搭建以及开发过程(注解，资源整合，高级特型，本地热部署)
- spring security
