#### 封装

把数据和方法封装在一起，可以对数据进行验证

如果在构造方法里使用set方法，仍然可以对数据进行验证

~~~java
//1.将属性私有化
//2.提供公共的set方法来修改私有的属性的值
//3.提供公共的get方法来获取私有属性的值
public class Person{
    private String name;
	public Person(String name){
	setName(name)
    }
    public String getName(){
      return name;
    }

    public void setName(String name){
      this.name = name;
    }
}
~~~

//构造器必须用上往下完成调用才能通过编译，默认调用无参构造器

#### 多态

多态就是同一个接口，使用不同的实例而执行不同操作；多态的三个必要条件：**继承、重写、父类引用指向子类对象**。

- 动物类 动物=new 狗() | 父类动物的引用指向了一个实际的狗对象（左边是编译类型，右边是运行类型）

- 向上转型：将父类引用指向子类对象 **父类引用 父类对象名=new 子类对象())**

- 向下转型: 将父类引用转为子类对象子类引用 **子类对象名=(子类对象) 父类引用**

~~~java
//它的核心场景是当父类引用实际指向子类对象时，需要访问子类特有的方法或属性。
List<Animal> animals = new ArrayList<>();
animals.add(new Dog());
animals.add(new Cat());

for (Animal animal : animals) {
    if (animal instanceof Dog) {
        Dog dog = (Dog) animal; //向下转型
        dog.bark();
    } else if (animal instanceof Cat) {
        Cat cat = (Cat) animal; //向下转型
        cat.meow();
    }
}
~~~

- 动态绑定机制：调用对象方法时，该方法和该对象的运行类型绑定

~~~java
//运行类型是B,调用set方法时从下往上找，set中有get方法，调用运行类型的get方法
A a=new B();
a.set();   //返回10
class A{
    int i=20;
    set(){
        get();
    };
    int get(){
        return i;
    }
}
class B{
    int j=10;
    int get(){
        return j;
    }
}
~~~

#### 重写与重载

重写是子类与父类之间，有同名同参且返回类型也是父子或相同关系(如父类返回Object类型，子类返回String类型，String是Object的子类)的时候，子类对父类实现方法重写；

- 不能重写父类构造器
- 不能缩小父类方法的访问权限

重载是同一类中相同名字不同参数的方法实现重载

#### 包

区分相同名字的类，实质就是文件夹，当同时调用两个不同包中相同类名的类时，应该加上包名加以区别。

开发者把一组类和接口等打包，并定义自己的包。将相关的类分组，更容易地确定哪些类、接口、枚举和注释等是相关的。

~~~java
//声明包
package pkg1[.pkg2[.pkg3...]]
//导入包或包中的类
//若最后一个pkg是类命则只导入该类，通配符*导入该包中的全部类不包括子包
import pkg1[.pkg2[.pkg3...]]
//java中常用的包
import java.lang.*   //基本包，默认引用
import java.util.*   //工具类
import java.net.*    //网络开发
import java.awt.*    //GUI界面开发
~~~
