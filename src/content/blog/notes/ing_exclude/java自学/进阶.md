# springboot

## 注解

启动类：@SpringBootApplication、@MapperScan
配置类：@Configuration、@Bean
Controller：@RestController、@RequestMapping、@GetMapping、@PostMapping、@RequestBody、@PathVariable、@RequestParam、@Valid
Service：@Service、@Transactional、@Autowired、extends ServiceImpl
Mapper：@Mapper、extends BaseMapper
Entity：@TableName、@TableId、@TableField、@TableLogic
DTO：@Data、@NotBlank、@NotNull、@Email
测试：@SpringBootTest

## controller三种传参方式以及接口规范RESTful风格

| 方式 | 注解 | 参数位置 | 示例 |
| :---: | :---: | :---: | :---: |
| 查询/表单参数 | @RequestParam | URL ?key=value 或 form 表单 | /user?name=Tom&age=18 |
| 路径参数 | @PathVariable | URL 路径中 | /user/100 |
| 请求体参数 | @RequestBody | 请求体 JSON | POST /user，body：{"name":"Tom"} |

REST 风格说明：
1.用名词（复数）表示资源：/users
2.HTTP 方法:
GET    /users        # 获取用户列表
GET    /users/1      # 获取 id=1 的用户
POST   /users        # 创建用户
PUT    /users/1      # 整体替换 id=1 的用户
PATCH  /users/1      # 局部更新 id=1 的用户
DELETE /users/1      # 删除 id=1 的用户
