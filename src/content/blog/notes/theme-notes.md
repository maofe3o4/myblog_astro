## 把意象变成变量

主题设计的第一步，是把"感觉"翻译成**设计令牌（Design Tokens）**。
「小鸟游六花」给我的关键词是：夜空、邪王真眼、缎带、魔法。

于是主色定为苍蓝 `--brand: #2f7fd1`，再配缎带金与魔法紫。
「六」这个数字则延伸为**六色星辉**，循环用于标签着色：

| 索引 | 意象 | 色值 |
| --- | --- | --- |
| 0 | 邪王真眼 · 苍蓝 | `#2f7fd1` |
| 1 | 缎带 · 金 | `#d9a441` |
| 2 | 魔法 · 紫 | `#8a5cd1` |
| 3 | 黄昏 · 绯 | `#d35c8a` |
| 4 | 翠 · 青绿 | `#4caf87` |
| 5 | 夜 · 靛 | `#5b6cc4` |

## 明暗双主题

同一套令牌，只需覆盖 `:root[data-theme="dark"]` 下的表面与文字变量，
就能得到夜空版本。切换只需在 `<html>` 上改写 `data-theme`，零成本。

## 为什么不用 UI 框架

对这种规模的主题，**原生 CSS 变量**足够清晰且零依赖。
等需求变复杂（设计态预览、多套皮肤并存）时，再考虑引入更重的方案也不迟。
