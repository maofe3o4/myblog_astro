# 统计学+概率论+数理统计

## 概率论

### 随机事件的关系与运算

| 关系  |           符号           |        解释        |
| :---: | :----------------------: | :----------------: |
| 包含  |      $A \subset B$       | A发生必然导致B发生 |
| 相等  |         $A = B$          |      A和B相等      |
| 互斥  | $A \cap B = \varnothing$ | A和B不可能同时发生 |

| 运算  |          符号          |       解释       |
| :---: | :--------------------: | :--------------: |
|  并   |    $A \cup B = A+B$    | AB至少有一个发生 |
|  交   |    $A \cap B = AB$     |    AB同时发生    |
|  差   | $A - B=A \overline{B}$ |   A发生B不发生   |
| 对立  |     $\overline{A}$     |     A不发生      |

|       运算性质       |                                                                   符号表示                                                                   |
| :------------------: | :------------------------------------------------------------------------------------------------------------------------------------------: |
|        交换律        |                                  $$\begin{aligned}A \cup B = B \cup A \\ A \cap B = B \cap A\end{aligned}$$                                  |
|        结合律        |                $$\begin{aligned}(A \cup B) \cup C = A \cup (B \cup C) \\ (A \cap B) \cap C = A \cap (B \cap C)\end{aligned}$$                |
|        分配律        |       $$\begin{aligned}A \cap (B \cup C) = (A \cap B) \cup (A \cap C) \\ A \cup (B \cap C) = (A \cup B) \cap (A \cup C)\end{aligned}$$       |
| 对偶律（德摩根公式） | $$\begin{aligned}\overline{A \cup B} = \overline{A} \cap \overline{B} \\ \overline{A \cap B} = \overline{A} \cup \overline{B}\end{aligned}$$ |

**德摩根公式推广**到多个事件以及可列个事件的场合：

$$
\begin{aligned}
\overline{\bigcup_{i=1}^{\infty} A_i} &= \bigcap_{i=1}^{\infty} \overline{A_i} \quad & \overline{\bigcap_{i=1}^{\infty} A_i} &= \bigcup_{i=1}^{\infty} \overline{A_i} \\
\overline{\bigcup_{i=1}^{n} A_i} &= \bigcap_{i=1}^{n} \overline{A_i} \quad & \overline{\bigcap_{i=1}^{n} A_i} &= \bigcup_{i=1}^{n} \overline{A_i}
\end{aligned}
$$

### 概率基本公式

概率加法公式：

$$
P(A+B) =
\begin{cases}
P(A)+P(B)-P(AB) & AB\text{任意} \\
P(A)+P(B) & AB\text{互斥} \\
P(A) \text{或} P(B) & B \subset A \text{或} A \subset B \\
P(A)+P(B)-P(A)P(B) & AB\text{独立}
\end{cases}
$$

概率减法公式：

$$
P(A-B) =
\begin{cases}
P(A)-P(AB) & AB\text{任意} \\
P(A)-P(B) & B \subset A \\
P(A) & A \subset B
\end{cases}
$$

乘法公式:

$$
P(AB)=P(A)P(B\mid A)
$$

全概率公式：

$$
P(B) = \sum\limits_{i=1}^{n} P(A_i) P(B \mid A_i)
$$

贝叶斯公式：

$$
P(A_i \mid B) = \frac{P(A_i) P(B \mid A_i)}{\sum\limits_{j=1}^{n} P(A_j) P(B \mid A_j)}
$$

### 三大抽样分布

#### $\chi^2$ 分布

若 $X_1,\ldots,X_n$ 相互独立且 $X_i\sim N(0,1)$，则

$$
\chi^2 = X_1^2 + X_2^2 + \cdots + X_n^2 \sim \chi^2(n)
$$

| 性质 | 结论 |
| :--- | :--- |
| 期望与方差 | $E(\chi^2)=n,\quad D(\chi^2)=2n$ |
| 可加性 | $\chi_1^2\sim\chi^2(n_1),\ \chi_2^2\sim\chi^2(n_2)$ 独立 $\Rightarrow\ \chi_1^2+\chi_2^2\sim\chi^2(n_1+n_2)$ |
| 大样本近似 | $n$ 大时 $\chi^2(n)\approx N(2n,4n)$，$\sqrt{2\chi^2}\approx N(\sqrt{2n-1},1)$ |
| 上侧分位数 | $P\{\chi^2>\chi^2_\alpha(n)\}=\alpha$ |

#### $t$ 分布

若 $X\sim N(0,1)$，$Y\sim\chi^2(n)$，且 $X,Y$ 独立，则

$$
T = \frac{X}{\sqrt{Y/n}} \sim t(n)
$$

| 性质 | 结论 |
| :--- | :--- |
| 对称性 | 密度函数为偶函数，关于纵轴对称 |
| 期望与方差 | $n>1$ 时 $E(T)=0$；$n>2$ 时 $D(T)=\dfrac{n}{n-2}$ |
| 极限 | $n\to\infty$ 时 $t(n)\to N(0,1)$ |
| 上侧分位数 | $t_\alpha(n)=-t_{1-\alpha}(n)$ |

#### $F$ 分布

若 $U\sim\chi^2(n_1)$，$V\sim\chi^2(n_2)$，且 $U,V$ 独立，则

$$
F = \frac{U/n_1}{V/n_2} \sim F(n_1,n_2)
$$

| 性质 | 结论 |
| :--- | :--- |
| 倒数 | $1/F\sim F(n_2,n_1)$ |
| 期望 | $n_2>2$ 时 $E(F)=\dfrac{n_2}{n_2-2}$ |
| 方差 | $n_2>4$ 时 $D(F)=\dfrac{2n_2^2(n_1+n_2-2)}{n_1(n_2-2)^2(n_2-4)}$ |
| 与 $t$ 分布关系 | $t^2(n)=F(1,n)$ |
| 上侧分位数 | $F_\alpha(n_1,n_2)=\dfrac{1}{F_{1-\alpha}(n_2,n_1)}$ |

### 参数估计

#### 点估计

##### 矩估计

以样本原点矩 $\hat\mu_k=\dfrac{1}{n}\sum\limits_{i=1}^n X_i^k$ 替换总体矩 $\mu_k=E(X^k)$，解 $\mu_k(\theta)=\hat\mu_k$。

| 总体 | 参数 | 矩估计 |
| :--- | :--- | :--- |
| 泊松 $P(\lambda)$ | $\lambda$ | $\hat\lambda=\bar X$ |
| 指数 $Exp(\lambda)$ | $\lambda$ | $\hat\lambda=1/\bar X$ |
| 均匀 $U(0,\theta)$ | $\theta$ | $\hat\theta=2\bar X$ |
| 正态 $N(\mu,\sigma^2)$ | $\mu,\ \sigma^2$ | $\hat\mu=\bar X,\quad \hat\sigma^2=\dfrac{1}{n}\sum\limits_{i=1}^n(X_i-\bar X)^2$ |

##### 最大似然估计

$L(\theta)=\prod\limits_{i=1}^n p(x_i;\theta)$（离散）或 $\prod\limits_{i=1}^n f(x_i;\theta)$（连续），解 $\dfrac{\partial\ln L}{\partial\theta}=0$；多参数时联立偏导方程组，有约束或似然不可导时直接由单调性取边界。

| 总体 | 参数的 MLE |
| :--- | :--- |
| 泊松 $P(\lambda)$ | $\hat\lambda=\bar X$ |
| 指数 $Exp(\lambda)$ | $\hat\lambda=1/\bar X$ |
| 均匀 $U(0,\theta)$ | $\hat\theta=X_{(n)}=\max\limits_{1\le i\le n}X_i$ |
| 正态 $N(\mu,\sigma^2)$ | $\hat\mu=\bar X,\quad \hat\sigma^2=\dfrac{1}{n}\sum\limits_{i=1}^n(X_i-\bar X)^2$ |

##### 无偏估计

| 标准 | 定义 | 常用结论 |
| :--- | :--- | :--- |
| 无偏性 | $E(\hat\theta)=\theta$ | $\bar X$ 无偏估计 $\mu$；$S^2=\dfrac{1}{n-1}\sum\limits_{i=1}^n(X_i-\bar X)^2$ 无偏估计 $\sigma^2$ |
| 有效性 | 同为无偏估计时，方差小者更有效 | 比较 $D(\hat\theta_1)$ 与 $D(\hat\theta_2)$ |
| 相合性 | $\hat\theta\xrightarrow{P}\theta\ (n\to\infty)$ | 矩估计、最大似然估计通常相合 |

#### 区间估计

$P\{\underline\theta<\theta<\overline\theta\}=1-\alpha$，称 $[\underline\theta,\overline\theta]$ 为置信度 $1-\alpha$ 的置信区间；$z_\alpha$ 表示标准正态上侧 $\alpha$ 分位数。

| 待估参数 | 条件 | 枢轴量及其分布 | 双侧置信区间 |
| :--- | :--- | :--- | :--- |
| $\mu$ | $\sigma^2$ 已知 | $\dfrac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0,1)$ | $\bar X\pm z_{\alpha/2}\dfrac{\sigma}{\sqrt n}$ |
| $\mu$ | $\sigma^2$ 未知 | $\dfrac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)$ | $\bar X\pm t_{\alpha/2}(n-1)\dfrac{S}{\sqrt n}$ |
| $\sigma^2$ | $\mu$ 未知 | $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$ | $\left[\dfrac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)},\ \dfrac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right]$ |
| $\mu_1-\mu_2$ | 独立正态，$\sigma_1^2=\sigma_2^2$ 未知 | $\dfrac{\bar X-\bar Y}{S_w\sqrt{\frac{1}{n_1}+\frac{1}{n_2}}}\sim t(n_1+n_2-2)$ | $(\bar X-\bar Y)\pm t_{\alpha/2}(n_1+n_2-2)S_w\sqrt{\dfrac{1}{n_1}+\dfrac{1}{n_2}}$ |
| $\sigma_1^2/\sigma_2^2$ | 独立正态 | $\dfrac{S_1^2/S_2^2}{\sigma_1^2/\sigma_2^2}\sim F(n_1-1,n_2-1)$ | $\left[\dfrac{S_1^2/S_2^2}{F_{\alpha/2}(n_1-1,n_2-1)},\ \dfrac{S_1^2/S_2^2}{F_{1-\alpha/2}(n_1-1,n_2-1)}\right]$ |

其中 $S_w^2=\dfrac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}$。

### 假设检验

显著性水平 $\alpha$；$p$ 值 $<\alpha$ 时拒绝 $H_0$。

#### 正态总体参数假设检验

| 检验对象 | 条件 | $H_0$ | 检验统计量（$H_0$ 成立时） | 双侧拒绝域 |
| :--- | :--- | :--- | :--- | :--- |
| 单个均值 | $\sigma^2$ 已知 | $\mu=\mu_0$ | $Z=\dfrac{\bar X-\mu_0}{\sigma/\sqrt n}\sim N(0,1)$ | $\lvert Z\rvert>z_{\alpha/2}$ |
| 单个均值 | $\sigma^2$ 未知 | $\mu=\mu_0$ | $T=\dfrac{\bar X-\mu_0}{S/\sqrt n}\sim t(n-1)$ | $\lvert T\rvert>t_{\alpha/2}(n-1)$ |
| 单个方差 | $\mu$ 未知 | $\sigma^2=\sigma_0^2$ | $\chi^2=\dfrac{(n-1)S^2}{\sigma_0^2}\sim\chi^2(n-1)$ | $\chi^2<\chi^2_{1-\alpha/2}(n-1)$ 或 $\chi^2>\chi^2_{\alpha/2}(n-1)$ |
| 两均值 | 独立，$\sigma_1^2,\sigma_2^2$ 已知 | $\mu_1=\mu_2$ | $Z=\dfrac{\bar X-\bar Y}{\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}}\sim N(0,1)$ | $\lvert Z\rvert>z_{\alpha/2}$ |
| 两均值 | 独立，$\sigma_1^2=\sigma_2^2$ 未知 | $\mu_1=\mu_2$ | $T=\dfrac{\bar X-\bar Y}{S_w\sqrt{\frac{1}{n_1}+\frac{1}{n_2}}}\sim t(n_1+n_2-2)$ | $\lvert T\rvert>t_{\alpha/2}(n_1+n_2-2)$ |
| 两均值 | 配对样本 | $\mu_D=0$ | $T=\dfrac{\bar D}{S_D/\sqrt n}\sim t(n-1)$ | $\lvert T\rvert>t_{\alpha/2}(n-1)$ |
| 两方差 | 独立正态 | $\sigma_1^2=\sigma_2^2$ | $F=S_1^2/S_2^2\sim F(n_1-1,n_2-1)$ | $F<F_{1-\alpha/2}$ 或 $F>F_{\alpha/2}$ |

#### 分布拟合检验

| 检验 | 统计量 | 分布或临界值 |
| :--- | :--- | :--- |
| $\chi^2$ 拟合优度 | $\chi^2=\sum\limits_{i=1}^k\dfrac{(n_i-np_i)^2}{np_i}$ | $\chi^2(k-r-1)$，$r$ 为估计参数个数 |
| K-S 单样本 | $D_n=\sup\limits_x\lvert F_n(x)-F_0(x)\rvert$ | $P\{\sqrt n D_n>D\}=2\sum\limits_{k=1}^{\infty}(-1)^{k-1}e^{-2k^2D^2}$ |
| 列联表独立性 | $\chi^2=\sum\limits_{i,j}\dfrac{(n_{ij}-E_{ij})^2}{E_{ij}}$ | $\chi^2((r-1)(c-1))$ |

### 方差分析

#### 单因素方差分析

$k$ 个水平，第 $i$ 组样本量 $n_i$，$n=\sum\limits_{i=1}^k n_i$；$H_0:\mu_1=\mu_2=\cdots=\mu_k$。

| 方差来源 | 平方和 | 自由度 | 均方 | $F$ |
| :--- | :--- | :--- | :--- | :--- |
| 组间（因素 $A$） | $S_A=\sum\limits_{i=1}^k n_i(\bar X_i-\bar X)^2$ | $k-1$ | $MS_A=\dfrac{S_A}{k-1}$ | $\dfrac{MS_A}{MS_E}$ |
| 组内（误差） | $S_E=\sum\limits_{i=1}^k\sum\limits_{j=1}^{n_i}(X_{ij}-\bar X_i)^2$ | $n-k$ | $MS_E=\dfrac{S_E}{n-k}$ | |
| 总和 | $S_T=\sum\limits_{i=1}^k\sum\limits_{j=1}^{n_i}(X_{ij}-\bar X)^2=S_A+S_E$ | $n-1$ | | |

拒绝域：$F>F_\alpha(k-1,\,n-k)$。

#### 双因素方差分析（无重复）

因素 $A$ 有 $r$ 个水平、$B$ 有 $s$ 个水平，每组合观测一次；$H_{01}:\alpha_1=\cdots=\alpha_r=0$，$H_{02}:\beta_1=\cdots=\beta_s=0$。

| 方差来源 | 平方和 | 自由度 | 均方 | $F$ |
| :--- | :--- | :--- | :--- | :--- |
| 因素 $A$ | $S_A=s\sum\limits_{i=1}^r(\bar X_{i\cdot}-\bar X)^2$ | $r-1$ | $MS_A=\dfrac{S_A}{r-1}$ | $\dfrac{MS_A}{MS_E}\sim F(r-1,(r-1)(s-1))$ |
| 因素 $B$ | $S_B=r\sum\limits_{j=1}^s(\bar X_{\cdot j}-\bar X)^2$ | $s-1$ | $MS_B=\dfrac{S_B}{s-1}$ | $\dfrac{MS_B}{MS_E}\sim F(s-1,(r-1)(s-1))$ |
| 误差 | $S_E=S_T-S_A-S_B$ | $(r-1)(s-1)$ | $MS_E=\dfrac{S_E}{(r-1)(s-1)}$ | |
| 总和 | $S_T=\sum\limits_{i=1}^r\sum\limits_{j=1}^s(X_{ij}-\bar X)^2$ | $rs-1$ | | |

拒绝域：$F_A>F_\alpha(r-1,(r-1)(s-1))$，$F_B>F_\alpha(s-1,(r-1)(s-1))$。
